03 / Method

Honest previews,
not magic thumbnails.

This prototype normalizes open CUBE, 3DL, and Hald CLUT assets into compact LUT atlases, then applies them locally with WebGL. Uploaded images stay in the browser and are never sent to a server.

Every reference image has an explicit pixel encoding. LUTr converts that encoding to the selected LUT's input, applies the LUT, then converts its output to the display. Results remain illustrative until each transform has verified input and output metadata.

Catalog downloads are composed from LUTr's normalized 25³ preview atlas. For mastering work, upload the original 3D CUBE in the converter so its source precision is preserved.
