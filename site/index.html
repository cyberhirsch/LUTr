05 / Method

Honest previews,
not magic thumbnails.

Every hosted transform is a metadata-rich CUBE. LUTr parses its floating-point samples locally and applies them with WebGL; uploaded images stay in the browser and are never sent to a server.

You can upload several reference images in one selection. LUTr decodes and color-tags each image locally; the selected reference controls every catalog tile. In the full-frame viewer, Up and Down move between references while Left and Right move through the currently filtered LUT results.

Every reference image has an explicit pixel encoding. LUTr converts that encoding to the selected LUT's input, applies the LUT, then converts its output to the display. Results remain illustrative until each transform has verified input and output metadata. Final-graded references are identified as display-referred material and are not treated as neutral camera originals.

Catalog downloads are composed directly from the canonical CUBE rather than an 8-bit preview image. Original CUBEs keep their native sample grids; converted sources declare their sampling method and limitations in the header.

The converter is also entirely local: LUTr parses the uploaded CUBE, composes the requested input and output conversions, resamples the chosen grid, and downloads the result without sending the LUT to a server.
